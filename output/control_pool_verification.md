# Stage V — Control-pool verification (GATE)

Generated by `R/stage_v_control_pool.R` (base R 4.3.3, seed 0). Data: authors'
replication zip (`dta.csv`, `stacked_fatal.csv`) + `callaway_replication.R`.
Numbers only — no substantive interpretation.

**Hypothesis under test:** the stacked design's 741 `change.type == "No Change"`
control agencies are mostly units permanently in the treated state
(`no.req == 1` every period), while CS/SA use only the 41 with `no.req == 0`
throughout.

**Verdict: CONFIRMED.** The 741 controls split **41 / 700** (always-`no.req==0` /
always-`no.req==1`), exactly the premise.

---

**Partitions agree exactly — 0 disagreements.** Every "No Change" agency fits one

Split is 41/700 → **premise holds; proceed.**

## V2 — Identifying variation in `stacked_fatal.csv`

- Estimation sample (non-missing `any.fatalities`): **171,906** rows
  = 171,171 control (`treat==0`) + 735 treated (`treat==1`).
- **Control units with any within-unit `no.req` variation: 0** — of 741 control
  agencies (and of 8,151 agency×stack units). Controls never switch `no.req`.
- **always-`no.req==1` control agencies: 700; number varying `no.req`: 0** (as
  expected — they are always in the treated state).

What the always-1 units *do* contribute (they supply **no** identifying variation
on the `no.req` coefficient):
- **Fixed effects:** they anchor the `agency_stack` unit FE (their own unit means
  within each of the 11 control-bearing stacks) and populate the `year.cohort`
  (stack × time) FE.
- **Share of estimation rows:** always-1 controls supply **161,700 of 171,906
  rows = 94.1%** of the sample used to fit `year.cohort`. They touch **231 of the
  310** distinct `year.cohort` levels present on the estimation sample.

## V3 — Trend divergence, 2000–2020 (`any.fatalities`)

Non-changers only; 700 always-1 vs 41 always-0; N = 15,561 agency-year obs.

| group | linear slope | SE | fitted 2000→2020 change |
|---|---|---|---|
| always-`no.req==1` (700) | **0.007686** | 0.000626 | **+0.15373** |
| always-`no.req==0` (41) | **0.005353** | 0.002454 | **+0.10706** |

- **Equal-slope test** (OLS interaction `year:group`): slope difference
  (always1 − always0) = **+0.002333**, SE 0.002655, t = 0.879, **p = 0.380** —
  cannot reject equal slopes.
- Difference in fitted 2000→2020 change: **+0.04667** (always1 higher).
- Annual means are in `output/v3_annual_means.csv`.

Flag (mechanism, not prose): both groups trend **upward**; the always-1 group has
the steeper slope and larger fitted rise (directionally consistent with the
`year.cohort` path being drawn toward treated-state dynamics), **but the slope
difference is not statistically significant.** SEs are unclustered OLS;
agency-clustering would widen them, so the "cannot reject equal slopes" result is
robust to clustering.

## V4 — Internal inconsistency check

| quantity | count |
|---|---|
| CS already-treated (`gname == 1987`, dropped from CS control pool) | 700 |
| Stacked clean controls (`treat == 0`) | 741 |
| **Agencies receiving BOTH treatments** | **700** |

The 700-agency both-set is **exactly** the always-`no.req==1` non-changers.

**Citations:**
- **Already-treated by CS:** `callaway_replication.R:17` —
  `dta$year.changed <- ifelse(is.na(dta$year.changed) & dta$no.req == 0, 0,`
  `ifelse(is.na(dta$year.changed) & dta$no.req == 1, 1987, dta$year.changed))`;
  then `att_gt(...)` at `callaway_replication.R:52-58` drops `gname == 1987`
  units as already-treated in the first period.
- **Clean controls by the stack:** the authors' build script
  `create_stacked_data.R` is **not in the replication zip**; `stacked_fatal.csv`
  carries every `change.type == "No Change"` agency as `treat == 0`. Our
  `R/reconstruct_stacked.R` replicates this rule
  (`nochange <- dta[dta$change.type == "No Change", ]; ... treat <- 0L`) and
  matches the authors' file exactly (assumptions.md §13).
